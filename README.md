 Student Grade Calculator

Student Grade Calculator is a web-based, developed using HTML, CSS, JavaScript and C programming. It allows users to enter student details and marks in five subjects. The application automatically calculates the total marks, percentage, grade and pass/fail status.

The frontend provides a simple and user-friendly interface, while the C backend performs the calculations. The frontend and backend communicate through HTTP requests using JSON data.

Technologies Used: HTML, CSS, JavaScript, C, Mongoose, GitHub, Vercel and Render.
